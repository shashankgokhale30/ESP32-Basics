# ESP32 Basics

This repository contains the ESP32 programs and small projects I have worked on while learning ESP32 and embedded systems.

I am using **ESP32 DevKit V1** with **Arduino IDE** and trying different sensors, modules and peripherals to understand how they work practically.

## What I have covered

* Onboard LED
* Touch Pin
* Bluetooth
* Servo Motor
* Relay
* DHT11 Temperature Sensor
* OLED Display
* Ultrasonic Sensor

## Tools Used

* ESP32 DevKit V1
* Arduino IDE
* Wokwi
* C/C++

I will keep adding more ESP32 experiments and projects here as I continue learning.
